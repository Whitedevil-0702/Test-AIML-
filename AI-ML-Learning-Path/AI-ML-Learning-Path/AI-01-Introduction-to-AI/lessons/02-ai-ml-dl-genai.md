# Lesson 02 — AI vs ML vs Deep Learning vs Generative AI

## A simple hierarchy

- **Artificial Intelligence (AI):** the broad field of building systems that perform tasks requiring capabilities such as reasoning, perception, or language.
- **Machine Learning (ML):** methods that learn patterns from data to make predictions or decisions.
- **Deep Learning (DL):** a family of ML methods built around multi-layer neural networks.
- **Generative AI:** systems that produce new content, such as text, images, audio, or code. Many modern systems use deep learning, but “generative AI” describes a capability/use pattern rather than the whole of AI.

These terms overlap, but they are not interchangeable.

## Analogy

Think of AI as the whole toolbox for making a system act intelligently. ML is one set of tools in that toolbox. Deep learning is a specialized set inside ML. Generative AI describes systems designed to generate outputs; many current examples are powered by deep learning.

## Examples

| Task | Possible approach |
|---|---|
| Follow a fixed eligibility policy | Rule-based program |
| Predict house prices from examples | ML regression |
| Detect objects in images | Often deep learning |
| Draft a response from a prompt | Often a generative model |
| Find the shortest route on a map | Search/optimization methods may be appropriate |

## Activity

Draw a four-circle or nested-box diagram for AI, ML, deep learning, and generative AI. Add two examples and explain why the categories overlap.

## Questions

1. Is every AI system a machine-learning system?
2. Is every ML model generative?
3. Can a generative AI answer be incorrect even if it sounds confident?

## Recap

Always identify the task, method, and output. A system's marketing label is not a technical description.
