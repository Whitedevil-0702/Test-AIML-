# Lesson 01 — What is Artificial Intelligence?

## What you will learn

- What people mean by artificial intelligence.
- Why not every automated program is machine learning.
- How to decide whether a problem needs an AI technique.

## Start with an example

Imagine a program that calculates a student's total marks using a fixed formula. A developer writes the formula explicitly. The program follows those rules; it does not learn the formula from examples.

Now imagine a system that examines many labeled examples of spam and legitimate messages, then learns patterns that help it classify a new message. This is a machine-learning approach.

AI is a broad field concerned with systems performing tasks associated with capabilities such as perception, language, planning, prediction, or decision support. Machine learning is one important family of methods within AI, not a synonym for all AI.

## Why it matters

The label “AI” does not tell you whether a system is reliable. You must ask what task it performs, what evidence it uses, how it is evaluated, and where it can fail.

## Activity: classify the problem

For each scenario, decide whether a fixed-rule program may be enough or whether learning from data could be useful:
1. Convert Celsius to Fahrenheit.
2. Flag potentially fraudulent transactions from historical examples.
3. Sort a list alphabetically.
4. Recognize objects in photographs.

There can be more than one valid design. Explain the trade-off rather than guessing a single fashionable answer.

## Check your understanding

1. Why is a calculator not usually described as machine learning?
2. What does a model learn from examples?
3. Give one reason an AI solution might be a poor choice.

## Common misconception

“AI always learns by itself.” Many AI systems use hand-written rules, search, optimization, or pretrained models. Some systems learn during training but do not update themselves during ordinary use.

## Recap

Start with the problem and success criteria. Choose AI only when it is a suitable method, not because the project needs an AI label.
