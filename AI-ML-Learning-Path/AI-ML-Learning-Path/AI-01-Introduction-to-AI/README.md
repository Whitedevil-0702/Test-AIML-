# AI-01 — Introduction to AI

**Level:** Beginner  
**Prerequisites:** None  
**Purpose:** Build a clear mental model before learning algorithms or libraries.

## Learning outcomes

By the end, you should be able to:
1. Explain AI, ML, deep learning, and generative AI in plain language.
2. Distinguish rule-based programming from learning patterns from data.
3. Identify whether a problem is prediction, classification, generation, search, or decision-making.
4. Describe the basic ML lifecycle and name at least two limitations.
