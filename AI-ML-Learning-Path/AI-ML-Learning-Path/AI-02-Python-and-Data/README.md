# AI-02 — Python and Data Foundations

**Level:** Beginner to early intermediate  
**Prerequisites:** Basic computer use; no prior Python required.

## Learning outcomes

- Read and write small Python programs.
- Use variables, strings, numbers, conditionals, loops, collections, functions, and imports.
- Explain errors and use simple debugging techniques.
- Describe rows, columns, features, labels, and missing data.
- Summarize and visualize a small dataset.

## Suggested sequence

1. Python syntax and expressions.
2. Conditions, loops, lists, dictionaries.
3. Functions, modules, exceptions, and files.
4. NumPy/pandas concepts and tabular data.
5. Descriptive statistics and simple charts.
6. Essential mathematics: averages, spread, probability intuition, vectors.

The existing repository's `002` Python program is the natural companion for syntax, data structures, functions, modules, files, exceptions, and OOP. The supplied ML links should not be used as a replacement for learning basic Python.
