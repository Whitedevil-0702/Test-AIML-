# Exercise 02 — Inspect a Dataset

**Goal:** Practice data thinking before fitting a model.

Use a small public or synthetic CSV. Do not use private team or personal data.

## Tasks

1. State what each row represents.
2. Identify columns that could be features and a possible target.
3. Count rows and columns.
4. Check missing values and duplicates.
5. Calculate basic summaries for numeric columns.
6. Create one chart and write two observations.
7. Identify one way the dataset might be biased or unrepresentative.

## Deliverables

- Notebook or script.
- Short README with dataset source and permitted use.
- Summary of observations and limitations.

Do not infer causation from a correlation or assume a dataset is representative simply because it is easy to download.
