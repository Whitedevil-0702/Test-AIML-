# Exercise 01 — Python Readiness

**Goal:** Confirm that a learner can write basic Python before moving to ML code.

## Tasks

1. Write a function `classify_score(score)` that returns a category based on clearly stated score ranges.
2. Given a list of numbers, calculate the count, minimum, maximum, and mean.
3. Given a list of words, count how many are longer than five characters.
4. Add input validation for an empty list or an invalid score.
5. Write three small tests, including an edge case.

## Reflection

- Which part took the most effort?
- What error did you encounter?
- How did you verify the result?

## Acceptance criteria

- Functions have clear names.
- Logic is correct for normal and edge inputs.
- No hard-coded output that only works for the sample.
- The learner can explain the solution.
