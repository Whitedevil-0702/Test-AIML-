# AI-06 — AI Project Development and Capstone

**Level:** Intermediate  
**Prerequisites:** Complete the relevant core modules. GenAI projects additionally require AI-05.

## Project workflow

1. Define the user and problem.
2. Decide whether ML/GenAI is justified.
3. Record data sources, permissions, and constraints.
4. Define a baseline and success metric.
5. Build the smallest working prototype.
6. Test typical, edge, and failure cases.
7. Document limitations, privacy, bias, and misuse risks.
8. Provide a reproducible setup and demo.
9. Request a peer review and present the result.

## Suggested project options

- **Traditional ML:** classify a small, permitted dataset and explain errors.
- **Data science:** analyze a public dataset and support conclusions with visualizations.
- **GenAI:** build a constrained question-answering demo over approved documents, with citations and an evaluation set. This option requires additional RAG resources first.

## Required deliverables

- Problem statement and user story.
- `README.md` with setup instructions.
- Source code/notebook and requirements file where appropriate.
- Dataset/source documentation.
- Evaluation report and error analysis.
- Limitations and responsible-use notes.
- Demo instructions or short presentation.
- Final PR and reviewer sign-off.

## Capstone rubric

| Criterion | Points |
|---|---:|
| Problem relevance and scope | 10 |
| Technical correctness | 20 |
| Data and evaluation quality | 20 |
| Reproducibility and code quality | 15 |
| Error analysis and limitations | 15 |
| Documentation and demo | 10 |
| Response to review / explanation | 10 |

A prototype is not automatically production-ready. Production deployment requires additional security, monitoring, reliability, privacy, and operational work.
