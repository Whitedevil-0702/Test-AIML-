# Progress Tracking

Record four distinct states separately:

1. **Resource status:** Not opened / Studied / Notes captured.
2. **Exercise status:** Not started / In progress / Submitted.
3. **Review status:** Not requested / In review / Changes requested / Approved.
4. **Competency status:** Not demonstrated / Demonstrated / Needs reinforcement.

Opening a link is not the same as completing a lesson, and submitting a task is not the same as demonstrating mastery.

Use `Members/PROGRESS_TEMPLATE.md` as a personal copy. Mentors may maintain a team overview separately, but avoid collecting unnecessary personal data.

## Suggested evidence

- PR or commit link.
- Notebook, script, or report path.
- Rubric score and reviewer.
- One concept the learner can explain independently.
- One improvement or limitation identified.
