## Suggested order of use

1. R02 and R04 for a gentle orientation to AI and ML.
2. R03 as a roadmap and topic index, not a checklist to complete in one sitting.
3. R01 for focused ML concepts after Python and data foundations.
4. R05 once the learner can read basic Python code and understand variables, lists, functions, and imports.
5. R06 only after its title and content are confirmed from the supplied NotebookLM analysis or direct video review.

## Resource-mapping rules

For each new resource, add:
- Stable resource ID and exact URL.
- Verified title and creator, if available.
- Module, lesson, and learning objective.
- Prerequisites and recommended reading order.
- Relevant timestamps only when verified.
- Required/supplementary status.
- Coverage strengths, gaps, and last-reviewed date.

## Known gaps

The current supplied set is strongest for introductory AI/ML and core machine learning. It does not yet provide a verified, complete learning sequence for:
- Python fundamentals from zero.
- NumPy/pandas and practical data preparation.
- Mathematics for ML.
- Neural networks and deep learning.
- Transformers, LLMs, embeddings, RAG, and GenAI evaluation.
- Application deployment, testing, monitoring, and MLOps.

Do not silently treat those areas as fully resourced. Add selected resources before the extended path is marked complete.
