# As-Is Reference Framework vs Proposed AI/ML Framework

## As-is findings from the supplied repository report

- The original repository is documentation-led and GitHub-centered.
- Program specifications, resource lists, assessment briefs, and member progress templates are core assets.
- Many coding tracks use ten progressively more integrated challenges.
- Branch/PR review is documented as the contribution workflow.
- The root README was described as title-only in the inspected snapshot.
- Rubrics, explicit mastery thresholds, prerequisite metadata, and automated grading were not consistent/evidenced in the inspected snapshot.

## Proposed adaptations for this course

| Existing pattern | Adaptation |
|---|---|
| Program structure documents | Standard module README, objectives, prerequisites, resources, and completion checklist |
| External resources | Centralized resource index with resource IDs and explicit lesson mapping |
| Ten assessment codes | A consistent beginner-to-capstone progression where it suits the module |
| Member workspace and progress file | Personal progress ledger that separates resource, exercise, review, and competency status |
| Branch/PR workflow | Peer/mentor review with a standard checklist and resubmission |
| Broad topic catalogues | A curated sequence with explicit prerequisites and known coverage gaps |
| Inconsistent rubrics | Shared rubric with adjustable team-defined thresholds |

## Boundaries

This new course package does not modify the original repository and does not claim the original report's entire inventory has been rechecked. The proposed AI/ML modules extend beyond the exact programs in the reference repository.
