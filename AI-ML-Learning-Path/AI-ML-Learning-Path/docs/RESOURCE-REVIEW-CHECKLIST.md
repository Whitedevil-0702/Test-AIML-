# Resource Review Checklist

Before making a resource required:
- [ ] URL opens and is the intended resource.
- [ ] Title and publisher are confirmed.
- [ ] Content is suitable for the learner's current prerequisites.
- [ ] The assigned lesson objective is explicit.
- [ ] The resource does not duplicate another resource without a reason.
- [ ] Any relevant timestamps are verified.
- [ ] Gaps and outdated claims are noted.
- [ ] The linked exercise requires learners to apply the concept.
- [ ] The resource is accessible to the team (cost, login, region, captions).
