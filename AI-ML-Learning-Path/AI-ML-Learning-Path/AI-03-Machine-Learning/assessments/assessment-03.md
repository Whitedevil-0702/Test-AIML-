# Assessment 03 — First ML Experiment

**Deliverable:** notebook or script, README, and a short results report.

## Requirements

1. Define a real problem and target.
2. Use a permitted, documented dataset.
3. Inspect missing values and basic distributions.
4. Create a suitable train/test split.
5. Build a simple baseline.
6. Train at least one model appropriate to the task.
7. Report an appropriate metric.
8. Inspect at least three errors or representative predictions.
9. Explain limitations and possible data leakage.

## Rubric (100 points)

| Criterion | Points |
|---|---:|
| Problem and target defined | 10 |
| Data inspection and preparation | 15 |
| Appropriate split and baseline | 15 |
| Model implementation and reproducibility | 20 |
| Metric selection and interpretation | 15 |
| Error analysis and limitations | 15 |
| Documentation and explanation | 10 |

## Completion rule

Suggested pass: 70/100, with no critical leakage or test-set misuse left unaddressed. A high score alone does not prove a model is safe or suitable for production.
