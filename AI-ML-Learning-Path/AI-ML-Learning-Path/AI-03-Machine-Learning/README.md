# AI-03 — Core Machine Learning

**Level:** Intermediate  
**Prerequisites:** Python basics, data inspection, mean/median intuition, and basic plotting.

## Learning outcomes

- Explain features, target, training, validation, and test data.
- Distinguish regression, classification, and clustering.
- Build a baseline with a standard ML library.
- Choose metrics that fit the problem.
- Detect obvious overfitting and data leakage.

## Lessons

- [01 — From data to model](lessons/01-from-data-to-model.md)
- [02 — Regression and classification](lessons/02-regression-classification.md)
- [03 — Evaluation and leakage](lessons/03-evaluation-and-leakage.md)

## Resource mapping

Start with R01 for the broader ML topic sequence. Use R04 for interactive intuition and R05 only after basic Python. R03 is a broader reference, not a requirement to study every topic in one pass.

## Assessment

Train a simple model on a permitted dataset. Compare against a baseline, report the metric, inspect errors, and document limitations.

## Completion checklist

- [ ] Dataset and target are clearly defined.
- [ ] Data split is appropriate.
- [ ] Baseline is reported.
- [ ] Metric is justified.
- [ ] Results are reproducible.
- [ ] Leakage risks and limitations are discussed.
