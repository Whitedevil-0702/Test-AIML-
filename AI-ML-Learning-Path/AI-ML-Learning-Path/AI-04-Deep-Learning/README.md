# AI-04 — Deep Learning and Neural Networks

**Level:** Advanced beginner / intermediate  
**Prerequisites:** Core ML, vectors/matrices intuition, and basic Python.

## Scope

1. Neurons, weights, biases, and activation functions.
2. Layers and forward propagation.
3. Loss functions and gradient-based learning at a conceptual level.
4. Training versus validation behavior.
5. A guided small neural-network experiment.
6. Optional directions: computer vision and NLP.

## Important coverage note

The currently supplied six resources do not provide verified complete coverage for this module. Add a beginner-friendly deep-learning course and an official framework tutorial before making this a required assessed module.

## Learning activity

Draw the flow input → layers → prediction → loss → parameter update. Explain each step without equations first. Then run a guided experiment using a small, suitable dataset.

## Completion checklist

- [ ] Explain what weights and biases represent.
- [ ] Describe what the loss measures.
- [ ] Explain why training repeats over examples.
- [ ] Compare training and validation behavior.
- [ ] Identify at least one limitation of the experiment.
