# Learning Paths

## Core path: absolute beginner to first ML project

| Order | Module | Prerequisite | Exit evidence |
|---:|---|---|---|
| 1 | AI-01 Introduction to AI | None | Explain AI, ML, deep learning, and GenAI with examples |
| 2 | AI-02 Python and Data | Basic computer use | Complete Python exercises and summarize a small dataset |
| 3 | AI-03 Machine Learning | Python basics and data literacy | Train and evaluate a baseline model |
| 4 | AI-03 Model Improvement | Core ML completed | Compare two models and explain the evaluation metric |
| 5 | AI-06 Traditional ML capstone | Modules 1–4 | A reproducible, documented ML project |

## Extended path: deep learning and generative AI

Continue only after learners can explain training, validation, test data, overfitting, and basic model evaluation.

1. AI-04 Deep Learning.
2. AI-05 Generative AI and LLMs.
3. AI-06 AI Project Development.
4. Capstone: a clearly scoped AI application with documented evaluation and limitations.

## Optional branches

- **Data Science:** spend more time on statistics, SQL, exploratory data analysis, and visualization.
- **ML Engineering:** focus on pipelines, APIs, tests, deployment, monitoring, and reproducibility.
- **Generative AI Engineering:** focus on prompting, embeddings, retrieval, grounded answers, evaluation, and data privacy.
- **Computer Vision / NLP:** defer until the core ML and deep-learning modules are completed.

## Recommended pace

A reasonable starting cadence is 4–6 hours per week, but duration depends on prior coding experience. Do not use a calendar deadline as a substitute for the module completion criteria.
