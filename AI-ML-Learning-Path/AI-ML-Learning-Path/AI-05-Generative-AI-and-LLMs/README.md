# AI-05 — Generative AI and Large Language Models

**Level:** Advanced beginner / intermediate  
**Prerequisites:** Core ML concepts; deep-learning concepts recommended.

## Scope

1. What generative models do and do not do.
2. Tokenization and next-token prediction at a high level.
3. Prompts, context windows, and structured outputs.
4. Embeddings and semantic retrieval.
5. Retrieval-augmented generation (RAG) as a system pattern.
6. Evaluation, hallucinations, privacy, and prompt-injection risks.
7. Using a model API safely (optional implementation).

## Starter exercise

Compare two prompts for the same low-risk task. Define a rubric for correctness, completeness, and unsupported claims. Record several outputs and discuss variation.

## Responsible-use checklist

- Do not send secrets or personal data to a model without authorization.
- Treat model output as untrusted until checked.
- Cite or retrieve source material for factual answers where appropriate.
- Test refusal and failure cases.
- Clearly disclose limitations to users.
