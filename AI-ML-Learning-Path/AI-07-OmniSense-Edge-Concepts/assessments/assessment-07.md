# Assessment 07 — OmniSense Edge Core Concepts

## Objective

Demonstrate conceptual understanding and a small, reproducible experiment across neural networks, optimization, audio representations, anomaly detection, CNNs, and graph neural networks.

## Required submission

Create a branch named `feature/omnisense-core-concepts-<your-name>` and submit a pull request containing:

1. A concept map linking neural networks, loss/optimization, and model evaluation.
2. A waveform and spectrogram experiment, with preprocessing details.
3. An autoencoder reconstruction-error experiment or a clearly documented equivalent walkthrough.
4. A CNN filter explanation or visualization.
5. A small equipment graph with nodes, edges, and a neighborhood-aggregation example.
6. A README explaining setup, reproduction steps, findings, and limitations.

If an implementation is not feasible, a well-labelled conceptual notebook or worked example is acceptable when the reason is stated. Do not fabricate experiment results.

## Rubric (100 points)

| Criterion | Points | Evidence expected |
|---|---:|---|
| Conceptual accuracy | 25 | Correct explanations of network components, gradients, spectrograms, autoencoders, CNNs, and GNNs |
| Reproducibility | 20 | Clear steps, dependencies, inputs, and outputs |
| Experiment quality | 20 | Appropriate comparisons, plots, and a clear separation of observation from assumption |
| Evaluation and limitations | 20 | Discusses false positives/negatives, data quality, distribution shift, and what the experiment cannot prove |
| Communication and Git workflow | 15 | Organized files, meaningful commits, readable PR, and useful peer-review responses |

## Completion standard

A resource is not considered mastered just because it was watched. The reviewer should be able to reproduce or inspect the evidence and ask the learner to explain the main choices and limitations.

## Reviewer checklist

- [ ] The learner distinguishes training loss from real-world performance.
- [ ] Audio preprocessing and representation are documented.
- [ ] Anomaly thresholds are justified rather than guessed without explanation.
- [ ] Claims about CNNs and GNNs match the evidence provided.
- [ ] Limitations and next steps are included.
- [ ] The PR includes reproducible evidence and responds to feedback.
