# Hands-on Labs

Complete the labs in order. These are learning exercises, not evidence that an industrial system is production-ready.

## Lab 1 — Neural network concept map

- Draw an input → hidden layer(s) → output diagram.
- Label weights, biases, and activation functions.
- Explain how the prediction would be evaluated for a clearly defined task.

**Evidence:** diagram + explanation.

## Lab 2 — Gradient descent visualization

- Visualize parameter updates on a simple objective.
- Try at least two learning rates.
- Describe convergence or instability observed.

**Evidence:** notebook/code + plot + observations.

## Lab 3 — Audio representation

- Load or generate a short audio sample.
- Plot the waveform and a spectrogram.
- Record sample rate, duration, and preprocessing decisions.

**Evidence:** reproducible notebook + plots + limitations.

## Lab 4 — Reconstruction-error experiment

- Train or inspect a toy autoencoder example.
- Compare reconstruction errors on examples resembling training data and deliberately different examples.
- Explain why this is not sufficient to claim robust anomaly detection.

**Evidence:** notebook/code + error plot + threshold rationale.

## Lab 5 — CNN filter intuition

- Apply a simple filter/kernel to an image or inspect a visualization.
- Describe the patterns it highlights.
- Explain why a toy result is not proof of defect-detection performance.

**Evidence:** image/diagram + explanation.

## Lab 6 — Equipment graph

- Define nodes and edges for a fictional machine.
- Pick one node and list its neighbors.
- Demonstrate a simple neighborhood aggregation concept manually.

**Evidence:** graph diagram + node/edge table + explanation.

## Team review

Ask a teammate to check:
- Can the explanation be understood without the video?
- Is the experiment reproducible?
- Are claims supported by the evidence?
- Are assumptions and limitations explicit?
