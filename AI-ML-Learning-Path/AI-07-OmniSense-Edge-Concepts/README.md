# AI-07 — OmniSense Edge: Core Concepts

This module extends the AI/ML learning path with concepts relevant to **OmniSense Edge**, a project concept that combines machine acoustics, visual inspection, and equipment-relationship context.

## Learning outcomes

By the end of this module, a learner should be able to:

- Explain the roles of layers, weights, biases, activation functions, loss, gradient descent, and backpropagation in a neural network.
- Explain how audio signals can be represented as spectrograms for model input.
- Describe how an autoencoder can learn a baseline of normal machine sounds and flag unusual reconstruction error.
- Explain the purpose of convolutional filters in image processing.
- Describe how graph neural networks represent components and their relationships.
- Identify what must be tested before using these techniques in an industrial setting.

## Learning cycle

For each lesson: **Learn → Explain in your own words → Experiment → Build → Submit for review**.

Do not treat watching a video or reading a resource as proof of mastery. Submit notes, diagrams, code/notebooks, test results, and a short explanation of limitations.
